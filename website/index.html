HOW IT WORKS

"Dead simple to set up."

STEP 01

One MSI. That's it.

Download PauseCat_Installer.msi. WiX handles WebView2 and registers autostart.

STEP 02

Right-click. Settings.

Set intervals (1 min – 4 hours), break duration, and mode. Every setting has live preview.

STEP 03

Work. Break. Repeat.

GDI capture → Rust blur → WebView2 overlay. Timer pauses automatically on screen lock.
