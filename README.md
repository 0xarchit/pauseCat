# PauseCat

PauseCat is a lightweight Windows background application built in Rust that encourages users to take periodic breaks through a full-screen immersive reminder experience. The reminder uses background blur and animated visuals to reduce fatigue and improve productivity.

## Tech Stack
- **Language:** Rust
- **System APIs:** Win32 (via windows-rs)
- **UI Rendering:** WebView2 (HTML/CSS/JS)

## Build Prerequisites
- **Rust stable toolchain** (latest)
- **WebView2 runtime** (pre-installed on Windows 10/11)
